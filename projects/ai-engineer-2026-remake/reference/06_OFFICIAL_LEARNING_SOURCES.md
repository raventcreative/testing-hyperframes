# Referensi resmi untuk akurasi materi

Rujukan ini memvalidasi istilah umum di roadmap. Ini **bukan klaim** bahwa ada satu urutan sertifikasi universal untuk semua pekerjaan AI Engineer.

1. Google for Developers — **Machine Learning Crash Course**. Memuat dataset, model, training, evaluasi, generalisasi dan overfitting.  
   https://developers.google.com/machine-learning/crash-course/
2. PyTorch — **Learn the Basics**. Pengantar end-to-end ML workflow, tensor dan training neural network.  
   https://docs.pytorch.org/tutorials/beginner/basics/intro
3. OpenAI Agents SDK — **Tools**. Agent menggunakan tools untuk mengakses data, kode dan API; pengaturan izin dan fungsi sesuai lingkungan.  
   https://openai.github.io/openai-agents-python/tools/
4. OpenAI Agents SDK — **Tracing**. Pemantauan event seperti panggilan model, tool usage, handoff dan guardrails untuk debugging.  
   https://openai.github.io/openai-agents-python/tracing/
5. Google for Developers — **Problem Framing**. Pentingnya memilih pendekatan ML berdasarkan masalah dan metrik keberhasilan.  
   https://developers.google.com/machine-learning/problem-framing/

**Catatan untuk pembuat materi:** RAG, API, agent, dan evaluasi AI punya implementasi yang bervariasi. Video menggunakan metafora mekanik untuk pembelajaran dasar; jangan menyamakannya secara harfiah dengan desain arsitektur software tertentu. Klaim pengembangan model dan deployment harus dijelaskan sebagai tahapan praktik, bukan hasil otomatis.
