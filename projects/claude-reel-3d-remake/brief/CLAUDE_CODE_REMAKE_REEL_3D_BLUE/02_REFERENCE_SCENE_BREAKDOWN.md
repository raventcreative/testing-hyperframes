## Motion DNA yang benar-benar terlihat

1. Presenter cutout berulang di dasar frame; tangan berubah pose dan ekspresi; tampil sebagai narator yang menemani penjelasan.
2. Pola baca `headline atas → UI/prop tengah → presenter bawah`, dengan sebagian besar adegan memakai latar putih, teks hitam, penekanan merah.
3. Elemen perantara: numbered step tiles, pointer/cursor, selection bracket, folder, chat window, phone, progress/status.
4. Pergantian major topic berlangsung cepat, sering berupa pergantian komposisi tegas dengan objek masuk berurutan; ada scaling, pop, fanning, slide, dan cursor emphasis.
5. Ritme scene terutama mengikuti narasi; screenshot tidak hanya ditempel datar, melainkan dibesarkan, ditandai, dan dibandingkan.
6. Contoh animasi hasil ditampilkan di dalam phone mockup sebagai bukti visual; final video memakai recap dan CTA yang mudah dipahami.

## Yang belum bisa dipastikan dari final MP4

- Apakah karakter asli 2D rig, sprite, 3D yang sudah di-render, atau gabungan; **jangan mengklaim engine pembuatnya**.
- Nama preset easing, plugin efek, software compositing, sumber SFX, dan timecode cut pada frame sub-detik; itu perlu ditentukan/diukur saat remake.
- Keakuratan UI Claude Code dan fitur voice key saat ini. Jangan mendorong pengguna memasukkan API key atau pembayaran tanpa verifikasi/consent.

## Keputusan remake

Pertahankan **struktur pesan enam langkah**, *hierarki UI yang mudah dibaca*, dan *rhythm guided by VO*. Ganti sepenuhnya identitas kreator asli: latar putih/merah menjadi gradient biru asli user, presenter manusia 2D menjadi maskot 3D user, typography menjadi Poppins, objek dibuat dimensional, dan transisi dibuat punya hubungan fisik antar-scene. **Jangan re-use karakter, logo, footage, komposisi identik, klaim angka, atau musik creator original di output final.**
