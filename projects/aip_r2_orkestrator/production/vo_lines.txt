AI agent kamu makin banyak, tapi makin berantakan? Ini empat open source gratis buat ngaturnya.
Satu, OpenHands Agent Canvas. Satu pusat kontrol buat jalanin Claude Code, Codex, sampai Gemini, di laptop, server, atau cloud.
Dua, Paperclip. Kamu bikin perusahaan isi AI agent: ada struktur tim, tugas, budget, dan approval dari kamu.
Tiga, Orca. Satu agent jadi koordinator, bagi tugas ke agent lain, masing-masing kerja paralel di worktree sendiri.
Empat, Team AI dari Tencent. Skill, rules, sama MCP semua agent di tim disimpan di satu repo Git, terus sync otomatis.
Keempatnya open source, gratis. Cuma, model AI-nya tetap pakai akun atau API kamu sendiri.
