# Starter Prompt 3D — gratis (hand-out DM untuk komentar "3D")

Tiga prompt awal untuk bikin landing page dengan produk "melayang" 3D, siap ditempel ke Claude (atau AI lain yang bisa menulis kode).
Ganti semua yang ada di [kurung siku] dengan data klien. Hasilnya satu file `index.html` yang bisa langsung dibuka di browser.

Cara pakai
1. Copy satu prompt di bawah, isi bagian [ … ], tempel ke Claude.
2. Simpan kode yang dibuat sebagai `index.html`, buka di browser (cek juga di HP).
3. Minta revisi pakai bahasa biasa ("judul lebih besar", "warna tombol ganti hijau", "produknya muter lebih pelan").
4. Ganti foto produk dengan foto klien (PNG tanpa latar paling bagus), teks, nomor WhatsApp, dan alamat.

Catatan jujur: hasil tiap AI beda-beda dan biasanya perlu 2–3 kali revisi. Pastikan foto, logo, dan teks memang milik/izin klien.
Harga jasa kamu tentukan sendiri sesuai klien dan scope (jumlah halaman, revisi, domain/hosting, siapa yang siapin konten).

## 1 · Kedai kopi
Buat landing page satu halaman untuk kedai kopi bernama [NAMA KEDAI] di [KOTA], dalam SATU file HTML (CSS dan JavaScript di dalam
file, boleh pakai GSAP atau Three.js dari CDN). Gaya: hangat, premium, warna espresso cokelat tua dengan aksen karamel, font sans-serif
tebal untuk judul. Bagian hero: kiri = nama kedai, judul besar "[TAGLINE]", satu kalimat deskripsi, tombol "Pesan sekarang" (link ke
WhatsApp [NOMOR]) dan tombol "Lihat menu"; kanan = foto produk [cup-kopi.png] yang melayang naik-turun pelan, sedikit berputar 3D
saat mouse digerakkan / saat di-scroll, dengan bayangan lembut di bawahnya dan beberapa biji kopi kecil yang mengorbit. Di bawah hero:
3 menu andalan (foto, nama, harga [ISI]), jam buka, alamat + tombol peta, dan footer. Responsif dan tetap rapi di HP (hero jadi satu
kolom, produk di atas judul). Animasi masuk halus saat bagian muncul ke layar. Pakai gambar placeholder kalau file belum ada.

## 2 · Toko sepatu / fashion
Buat landing page satu halaman untuk brand sneakers lokal [NAMA BRAND], dalam SATU file HTML (CSS + JS di dalam file, boleh GSAP /
Three.js dari CDN). Gaya: energik, biru elektrik dengan aksen hijau lime, judul tebal besar. Hero: judul "[TAGLINE]", deskripsi singkat,
tombol "Belanja sekarang" (link ke [MARKETPLACE / WHATSAPP]) dan "Lihat koleksi"; foto sepatu [sepatu.png] melayang miring, berputar
pelan seperti di atas meja putar, bayangan di bawah, bola-bola kecil warna lime mengorbit. Lalu: grid 6 produk (foto, nama, harga
[ISI], ukuran), panduan ukuran sederhana, testimoni 3 kartu [ISI ASLI DARI KLIEN], dan footer dengan kontak. Responsif di HP, animasi
muncul saat scroll, tombol punya efek hover.

## 3 · Toko roti / kue rumahan
Buat landing page satu halaman untuk toko roti rumahan [NAMA TOKO], dalam SATU file HTML (CSS + JS di dalam file, boleh GSAP / Three.js
dari CDN). Gaya: hangat dan ramah, latar terakota/oranye dengan aksen kuning mentega. Hero: judul "[TAGLINE]", deskripsi singkat,
tombol "Pesan antar" (WhatsApp [NOMOR]) dan "Lihat menu"; foto produk [croissant.png] melayang dengan goyangan 3D halus, bayangan
lembut, butiran gula/partikel kecil mengorbit. Lalu: menu harian dalam kartu (foto, nama, harga [ISI]), info pre-order dan jam ambil,
area pengiriman, dan footer. Responsif di HP, ringan dibuka (kompres gambar, tanpa video besar).
