**Format:** vertical 1080×1920, 30 fps, final length = duration VO + short visual tail (up to 0.8 s). **Timeline below estimates 72.0 s**, not a locked cut list. ## Visual grammar

- World: background exact user PNG, dark navy/blue cinematic atmosphere. Extra layers use subtle depth, grid lines ≤ 0.06 opacity, tiny dust, screen-space reflections, no excessive neon.
- Text: white `#FFFFFF`, cyan `#00D0FE`, Poppins 700/400. The cyan word highlight uses a 0.22–0.36s underline sweep, restrained shadow `0 0 14px rgba(0,208,254,.38)` on apex. No glowing every word.
- Panels: inlay gradient `linear-gradient(135deg, rgba(10,13,44,.94), rgba(41,75,119,.90))`, inner top-edge light, 1.5px border `rgba(0,208,254,.40)`, soft cast/contact shadow. Text contrast must survive mobile viewing.
- 3D mascot: **existing** asset from current Claude Code project. Narrator with *motivated gestures*, not always stuck waving at bottom. Appearance authentic; properly tailored jacket.
- Logo: **existing** original in upper-left x ≈ 64 px, y ≈ 100–135 px, width relative to original aspect ratio ≈ 110–170 px. A clipped light sweep traverses only the shape every 4–7 s; ambient pulse 1.00→1.035→1.00. In last second, settle and hold. Never redraw/retype brand.
- Camera and editing: controlled dolly/track/whip only to follow information. Use one continuous prop, click, cursor, or edge to motivate each transition; avoid spinning the entire screen, repeated zoom + blur, random glitch.

### Retiming rules

- A transition occupies the tail/head of adjacent clips; **do not add all durations onto 72 s**.
- Cut exactly on clause/word beat after analyzing final VO, not by forcing this table.
- If a sentence runs long, extend a meaningful in-scene action or split shot on a semantic change, never speed up the VO artificially.
- Two consecutive transitions must not have the same entrance signature. Use variable cadence: strong hook → calmer tutorial → high-energy step 5 → dramatic sixth step → controlled finale.
- The brightest glow/apex is for `SATU KALIMAT`, `06`, and `ANIMASI`. All other highlights are dimmer.
