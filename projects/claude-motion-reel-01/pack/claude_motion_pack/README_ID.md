# PAKET PRODUKSI — CLAUDE CODE MOTION REEL 01

**Konsep:** Screenshot Claude Code yang tadinya diam berubah menjadi motion graphic editorial premium.

**VO sudah disertakan:** 39,549 detik. Target video 40,00 detik, vertikal 1080 × 1920, 30 FPS.

## Cara pakai

1. Ekstrak ZIP ini di dalam folder project Claude Code yang selama ini kamu gunakan, **tanpa menghapus atau mengganti file project lama**. Misalnya hasilnya menjadi `claude_motion_pack/`.
2. Di Claude Code, buka project yang sama, lalu paste perintah berikut:

   `Read claude_motion_pack/CLAUDE_CODE_EXECUTE.md in full, inspect my current project, and implement the production plan. Use claude_motion_pack/assets as the real source footage. First deliver a 0–6-second visual proof for review; then complete and quality-check the full ~40-second vertical video.`

3. Claude Code harus memeriksa font, background, identitas brand, dan maskot 3D **yang sudah ada di project kamu**. File-file itu memang tidak dikirim ulang dalam ZIP.
4. Preview 6 detik pertama harus terlihat bagus dulu. Setelah cocok, lanjutkan video 40 detik.

## Isi paket

- `CLAUDE_CODE_EXECUTE.md`: prompt utama bahasa Inggris, lengkap dengan storyboard dan aturan render.
- `VOICEOVER_TRANSCRIPT_REFERENCE.md`: naskah VO referensi untuk dicek terhadap file suara asli.
- `assets/vo/master_vo.mp3`: VO ElevenLabs asli yang kamu kirim, belum diubah.
- `assets/ui/`: 9 gambar asli dari kamu.
- `assets/recording/claude_navigation_raw.mp4`: screen recording asli dari kamu.
- `reference_style/`: pedoman produksi dan satu video contoh house style yang kamu upload.

## Yang perlu diperhatikan

- Semua gambar UI dan rekaman adalah **aset nyata**, bukan hasil generasi AI baru.
- Waktu di storyboard adalah estimasi berdasarkan jeda suara, **bukan timestamp tiap kata yang sudah diverifikasi**. Claude Code wajib melakukan alignment audio sebelum mengunci animasi final.
- Logo Claude 3D punya beberapa warna yang mencuat di pinggiran transparansi. Bersihkan artefak pinggirannya ketika compositing tanpa mengubah bentuk/identitas logo.
- Jangan unggah thumbnail yang menjanjikan hasil terlalu fantastis kalau preview-nya belum sesuai. Target 1.000–10.000 view adalah target distribusi, bukan hasil yang bisa dijamin oleh efek visual semata.

## Output yang wajib kamu minta dari Claude Code

1. Preview 0–6 detik yang dapat diputar.
2. Final Reel 1080 × 1920 H.264/AAC, ±40 detik, tanpa visual burik.
3. Screenshot/contact sheet dari scene utama.
4. Ringkasan hasil QA (resolusi, FPS, sinkronisasi VO, tampilan logo, typo dan black frame).
