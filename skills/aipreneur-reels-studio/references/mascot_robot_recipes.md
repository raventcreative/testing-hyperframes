# Mascot + robot recipes (apply to every AIpreneur reel with the 3D mascot host and the AIpreneur robot)
Distilled from technique_bank.md + prompt_motion_catalogue.md (credits there) + the client's external skills. Client
brand/format rules still win (brand.md, client_rules.md). Pick 3–5 per reel; never reuse the same set two reels in a row.

## Structure
- Hook in the first second; a different technique on every beat; one clean final frame (CTA card, mascot whole).
- Arc for explainers: chaos → control → clarity → brand (problem pile-up → AI/robot sorts it → one clear result → AIpreneur end card).
- "Spinning pain list" hook: a fast vertical list of problems (too fast to read, rhythm on the beat) that slows and lands on
  the one this reel solves — the mascot points at it as it locks.

## Mascot & robot as the guide object (through-line)
- ONE guide carries every hand-off and never teleports: alternate per reel — the robot's face screen, the mascot's
  pointing hand, or a cyan #01ccf7 accent dot. The guide turns into the next UI element (screen → button → card → chart →
  logo) and becomes the AIpreneur logo on the CTA card.
- Robot screen as a portal: camera pushes into the robot's visor/screen and the next scene is inside it (match cut).
- Mascot presses a button that expands into the next page (shared element; the label grows to headline size).
- Accent dot journey: it becomes the dot on an "i", draws a chart line, floods the frame (scale past all four corners in
  ≈0.35 s), then shrinks back into the robot's eye.

## Camera & motion
- Camera never still: slow push 1.0 → 1.04 per scene; each scene starts at the previous end zoom; one eased move per
  scene; never zoom in then out back-to-back; no reversals.
- Mascot/robot entrances and reactions on small-overshoot springs (no bouncy easing); nothing appears from nothing
  (grow, unfold, mask reveal). Robot glides (hover), mascot hops/leans; both point at what the VO names.
- Motion blur from subframes on fast moves (3 for UI moves, 8 for whips/flights).

## Explainer devices that fit the hosts
- Process fill: each step pours into a container (labelled) until it's complete — robot pours, mascot checks.
- One concept, several visual genres: the same idea re-explained in 2–3 styles (diagram → voxel → kinetic type) for longer reels.
- Kinetic type in brand only: the next word revealed through a mask of the outgoing word; a strikethrough becomes the next
  underline; "words as architecture" — the last line stands on blocks built by earlier words.

## Sound & VO
- VO: multiple takes when needed, splice weak lines, trim pauses > 0.28 s to 0.2 s, level phrases; word timings per
  pause-split segment so per-word captions land exactly.
- Music ducked ~9 dB under speech (300 Hz–4 kHz band), the music drop on the key action line; SFX by measured peak;
  a hit on each scene change; −14 LUFS.

## QA additions
- Vertical recomposed, not cropped. Stills at fixed times + decoded frames from the final MP4 + a scan for single-frame
  pops, on top of the every-second no-cut-text audit (qa.md).
