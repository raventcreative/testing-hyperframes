## THE WORLD CONTRACT (w02–w10) — read carefully
1. Your slot starts at the world's cut and lasts DUR(slot) = spoken duration + 0.55 s. For your first 0.55 s (`TR`) the PREVIOUS scene is
   still alive UNDER you: you must REVEAL yourself over it with your signature transition (below), starting from the rocket's nose
   (≈ (800, 880), exact per world in the table). During your LAST 0.55 s the next world reveals itself over you: keep everything moving
   to the very end (parallax never stops).
2. After the transition you are a full-screen, fully opaque world (you cover the navy plate).
3. Mask technique: `clip-path` on your `#wNN-world` wrapper. `circle()/ellipse()/polygon()/inset()` strings tween fine with GSAP; for
   complex/disjoint shapes use an inline SVG `<clipPath id="wNN-reveal" clipPathUnits="userSpaceOnUse">` (rects/polygons/paths/circles,
   animate their attrs/transforms with GSAP) + `clip-path: url(#wNN-reveal)`. Strokes do not count inside a clipPath — use filled shapes.
   Set `clipPath: "none"` right after TR (performance). Decorative transition elements (rings, dust, sparks, flashes) live OUTSIDE the
   clipped wrapper so they can draw over the previous world.
4. Title + progress chip (same layout in every world): title centred, top 300 px (one line, ≤ 900 px wide), styled in the world's style
   but ONLY Poppins 400/700 (client rule: font stays Poppins — style it with colour, stroke, shadows, gradients, texture masks, per-letter
   motion). Under it the progress chip (copy w01's `.w01-chip` markup/CSS, rename prefix): `N/10` + 10 dots, dots ≤ N cyan `#01ccf7`,
   chip `rgba(8,14,46,.86)`; it may be restyled slightly to fit (e.g. pixel corners in w03, ink border in w05) but stay recognisable.
   Title words pop on their spoken word (± 0.05 s). Apex accents on key words (see each world).
5. Parallax: far layers 40–200 px/s, mid 300–500, ground/near 900 px/s (matches the line). Long strips: generate the art in JS
   (seeded PRNG) wide enough for `speed × DUR + 1080`.
6. Something must happen on the spoken beats (the world reacts to the VO), plus 1–2 "wow" details per world (a creature, a gag, a
   particle moment). Keep ~0.4 s calm reading holds; motion smooth (no jitter except deliberate style choices like stickman boil or
   8-bit stepping).

## Code conventions (same as w01/s02 — deviations break the render)
- File = `<template>` with `<style>` + ONE root `<div data-composition-id="ID" data-width="1080" data-height="1920">` + `<script>` IIFE.
- **The runtime STRIPS the id of the template root** → never select the root by id. `const root = document;` and give every element a
  unique prefixed id/class (`w02-…`). Never `document.querySelector("#root")`. Prefix SVG ids too (`w02-reveal`).
- Timeline: `const tl = gsap.timeline({ paused: true })`, the `_sc` patch, `ft` (fromTo with immediateRender:false), `I(el, vars)` for
  initial states (applies now AND at 0), end with `tl.set({}, {}, DUR - 0.01)`, the seek-order render patch, then
  `window.__timelines["ID"] = tl`. Timeline duration must be ≤ DUR(slot) (loops: `(k + 1) * d <= D`).
- Deterministic only: no Math.random (seeded PRNG), no Date, no CSS animations/transitions, no requestAnimationFrame, no hf-seek
  listeners in scenes (only GSAP). Everything is seekable at any time in any order.
- Performance (45 s render on 4 CPUs): no full-screen `filter: blur()`/feTurbulence that changes per frame; blur/turbulence only on small
  elements; ≤ ~400 animated elements per scene; prefer transforms/opacity; SVG strips generated once.
- Assets: only files in `assets/` (icons, fonts, brand). No external URLs, no images from the web, no AI-generated images.
- Text: Poppins 400/700 only. Indonesian copy only as spoken / given here. No emoji glyphs (font has none) — use icons.
