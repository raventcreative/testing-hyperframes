## Transition choreography

Jangan beri semua scene efek berbeda: objek fisik memberi alasan perpindahan.

1. S01→S02: pantulan di kaca menjadi penanda batas dua layer.
2. S02→S03: sisi luar file membuka menjadi sleeve metadata C2PA.
3. S03→S04: C2PA badge bergeser, kamera masuk ke lapisan pixel konten.
4. S04→S05: garis pixel menjadi ruler karakter/teks.
5. S05→S06: scanner rail bergerak ke dua pemeriksa.
6. S06→S07: file asli berpindah dari comparison bay ke scanner, sementara badge berputar ke tray terpisah.
7. S07→S08: tepi file menjadi jalan kamera masuk ke loket inspeksi.
8. S08→S09: kamera mengikuti file bergerak ke alat verifikasi.
9. S09→S10: tiga hasil alat berubah jadi drawers.
10. S10→S11: laci unknown digeser menjadi alat pembanding klaim satu-klik.
11. S11→S12: gagang alat bergeser menjadi engsel clipboard checklist, revealing entire lab.

**Light:** diffuse big key upper-left; physical contact-shadow down/right. Depth planes: pale background; lab furniture and hero; near lens rail/mascot. Use small motion 6–12 frames anticipation, main action 10–18 frames, settle 8–12 frames, subject to VO. Highlight box bloom should **pulse once on the spoken keyword**, not constantly breathe. Continuous tiny lamp/compass motion allowed only if determinstic and subtle.
