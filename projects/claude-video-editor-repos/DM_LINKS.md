# 15 GitHub repos: turn Claude into a video editor

Kirim ke yang comment "VIDEO EDITOR". Semua repo dicek ada & publik di GitHub (24 Nov 2026). Star dibulatkan.

01. **yt-dlp**: Download source videos (★ 210k)  
    https://github.com/yt-dlp/yt-dlp
02. **Whisper**: Speech to text transcripts (★ 113k)  
    https://github.com/openai/whisper
03. **WhisperX**: Word-level timestamps for captions (★ 25.6k)  
    https://github.com/m-bain/whisperX
04. **FFmpeg Skill**: 42 FFmpeg editing tools for agents (★ 10.3k)  
    https://github.com/kajisho5/ffmpeg-skill
05. **Video Use**: Edit videos with coding agents (★ 31.5k)  
    https://github.com/browser-use/video-use
06. **Claude Shorts**: Long video into short clips (★ 490)  
    https://github.com/AgriciDaniel/claude-shorts
07. **Herk Edit Kit**: Reels & Shorts, transcript-driven cuts (★ 3.1k)  
    https://github.com/nateherkai/herk-edit-kit
08. **PySceneDetect**: Find every scene cut automatically (★ 5.6k)  
    https://github.com/Breakthrough/PySceneDetect
09. **Remotion Skills**: Official skills for video in React (★ 7.9k)  
    https://github.com/remotion-dev/skills
10. **Three.js Skills**: 3D scenes and objects for videos (★ 4.4k)  
    https://github.com/CloudAI-X/threejs-skills
11. **Motion Skills**: 56 motion graphics skills (★ 2.1k)  
    https://github.com/iart-ai/motion-skills
12. **Motion Graphics**: Motion design for Claude Code (★ 1.5k)  
    https://github.com/Barty-Bart/motion-graphics
13. **HyperFrames**: HTML to video, edit with Claude (★ 89k)  
    https://github.com/heygen-com/hyperframes
14. **OpenMontage**: Full agentic video production (★ 82.8k)  
    https://github.com/OpenMontageInc/OpenMontage
15. **Awesome Skills**: Curated list of video skills (★ 2.6k)  
    https://github.com/zhuyansen/awesome-claude-video-skills

Catatan: tiap repo punya lisensi sendiri (mis. OpenMontage AGPL-3.0, beberapa tanpa lisensi). Cek lisensinya sebelum dipakai untuk proyek komersial.
