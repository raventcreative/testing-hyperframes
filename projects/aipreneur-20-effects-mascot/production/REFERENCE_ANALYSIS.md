## Not copied
No human frame, room, creator logo, the reference app UI, its audio, words, cover designs or compositions. Only motion ideas, rebuilt as original HTML/CSS/WebGL.

## Weakness of the source we fix
Effects are a list; transitions rarely explain object relationships. Ours: one continuous motion journey, every cut hands one object to the next (see MOTION_TRANSITION_MAP.md).
