## Yang bekerja di source

1. Satu materi presenter menunjukkan enam gaya berbeda; value langsung tampak.
2. Pergantian chat prompt → video memberi penonton rasa demonstrasi.
3. Naming efek jelas dan dipadatkan.

## Kendala source untuk tujuan AIpreneur

1. Repeated UI interstitial membuat ritme putus-putus.
2. Transisi demo bergantung pada pergantian antar video, bukan logika object continuity.
3. Teks/angka dari creator asli tidak boleh dipakai sebagai bukti hasil sendiri.
4. Presenter live-action perlu diganti **maskot user existing**, dan kamera 3D harus bertanggung jawab terhadap ruang, bukan warping wajah.
