## 1) Tracker volume 30 hari (copy ke Notes / Google Sheets)
Isi tiap hari. Tujuannya bukan sempurna, tapi **jumlah percobaan naik** dan **tiap percobaan dicatat**.

| Hari | Target percobaan | Yang dikerjakan (konten / follow-up / iklan / olahraga) | Jumlah | Hasil yang kelihatan | 1 hal yang diperbaiki besok |
|---|---|---|---|---|---|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |
| … |  |  |  |  |  |
| 30 |  |  |  |  |  |

Rekap mingguan (hari 7, 14, 21, 28):
- Total percobaan minggu ini: ___ (minggu lalu: ___)
- 3 percobaan dengan hasil terbaik: ___
- Pola yang sama dari 3 itu: ___
- Yang aku stop / ganti: ___

Aturan main: (1) volume dulu, jangan nunggu mood; (2) catat jujur, termasuk yang gagal; (3) perbaiki **satu** hal per hari.

## 2) Prompt AI untuk bikin volume (Claude / ChatGPT / Gemini — bebas)
Ganti teks di [kurung siku].

**A. 10 draf naskah konten**
> Kamu penulis konten pendek untuk [bisnis/akun], audiens [siapa], gaya bahasa santai pakai "kamu". Buat 10 draf naskah video
> 30–45 detik tentang [topik]. Tiap draf: hook 1 kalimat (beda sudut tiap draf), 3 poin isi, 1 CTA. Jangan janji hasil, jangan
> mengarang angka. Tampilkan dalam tabel: No · Hook · Isi · CTA.

**B. 10 variasi iklan dari 1 produk**
> Produk: [nama + 3 manfaat utama + harga/penawaran]. Buat 10 variasi materi iklan untuk [platform]. Variasikan: sudut masalah,
> format (testimoni/demo/edukasi/cerita), dan hook. Tiap variasi: judul, teks utama ≤ 125 karakter, ide visual 1 kalimat.
> Tandai 3 yang menurutmu paling layak diuji duluan dan kenapa.

**C. Pesan follow-up yang tetap sopan**
> Calon pembeli nanya [produk] [X hari] lalu lalu belum balas. Buat 5 pesan follow-up WhatsApp/DM untuk 5 hari berbeda: singkat,
> sopan, tidak memaksa, tiap pesan kasih alasan baru buat balas (info stok, jawaban pertanyaan umum, bonus kecil, tanya kendala,
> penutup ramah). Maks 3 kalimat per pesan.

**D. Evaluasi mingguan dari tracker**
> Ini catatan percobaanku 7 hari terakhir: [tempel tabel]. Cari pola dari yang hasilnya paling baik, sebut 3 hal yang sebaiknya
> aku ulang dan 1 hal yang sebaiknya aku stop. Lalu susun target percobaan minggu depan yang realistis.

## Ingat
AI bikin volume jadi murah — drafnya cepat. Tapi yang ngecek, klik posting, dan kirim chat tetap kamu.
Angka di video (percobaan, kena, balasan, data iklan) adalah **ilustrasi**, bukan hasil yang dijanjikan.
