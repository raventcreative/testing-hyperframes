# DM · DADU — Lembar kerja "Pilih Dadu & Nampan" + perintah AI siap pakai
Isi lembar kerja ini SEBELUM keluar modal besar. Dadu = ide + cara kamu jalanin. Nampan = pasar. Lemparan = tiap percobaan
(promo, harga, konten, cara jualan). Prinsipnya: kunci dadu & nampan, ubah lemparannya — jangan ganti semua tiap meleset.

## 1. Nampan (pasar) — cek ukurannya dulu
| Pertanyaan | Jawabanmu |
|---|---|
| Siapa pembelinya? (spesifik: umur, kota, kebiasaan) | |
| Kira-kira berapa banyak orang seperti ini yang bisa kamu jangkau? (kecamatan / kota / online se-Indonesia) | |
| Pasarnya lagi tumbuh, stagnan, atau menyusut? Apa buktinya? | |
| Di mana mereka sekarang belanja / cari solusi? | |
| Kalau 1 dari 100 orang di situ beli, cukup nggak buat usahamu jalan? (hitung sendiri, jangan tebak) | |

## 2. Nampan ada lantainya? (masalahnya nyata)
| Pertanyaan | Jawabanmu |
|---|---|
| Masalah apa yang kamu selesaikan, dengan kata-kata pembeli sendiri? | |
| Di mana kamu dengar keluhan ini? (ulasan, chat, grup, komentar — tulis 3 contoh asli) | |
| Sekarang mereka pakai cara apa? Kenapa cara itu kurang? | |
| Mereka sudah pernah keluar uang untuk masalah ini? | |
Kalau kolom "3 contoh asli" kosong → nampanmu mungkin belum ada lantainya. Cari dulu sebelum bikin produk.

## 3. Dadu (ide + cara jalanin) — ada angka 6-nya?
| Pertanyaan | Jawabanmu |
|---|---|
| Ide dalam 1 kalimat: "Aku bantu [siapa] dapat [hasil] lewat [produk/jasa]" | |
| Versi paling kecil yang bisa dijual minggu ini (bukan ruko 3 lantai, bukan juga cuma 1 pesan sebulan) | |
| Hal yang BELUM PASTI (produk / pasar / harga / cara jualan). Kalau lebih dari 2 yang baru sekaligus → kurangi dulu | |

## 4. Log lemparan (tiap percobaan = 1 baris)
| # | Tanggal | Yang diubah (cuma 1 hal) | Hasil | Pelajaran | Lemparan berikutnya |
|---|---|---|---|---|---|
| 1 | | produk / penawaran / harga / cara jualan | | | |
| 2 | | | | | |
| 3 | | | | | |
Aturan: ubah satu variabel per lemparan. Ganti nampan (pasar) hanya kalau beberapa lemparan yang sudah diperbaiki tetap gagal
DAN catatanmu menunjukkan masalahnya di pasar — bukan karena ada ide baru yang lebih "kinclong".

## 5. Perintah AI siap pakai (Claude / ChatGPT / Gemini — isi [kurung] dulu; hasil AI = draf, cek lagi)
**A. Ringkas ulasan pembeli**
```
Ini kumpulan ulasan/komentar pembeli untuk [produk/kategori] (aku tempel di bawah). Ringkas jadi 1 halaman:
1) 5 hal yang paling sering dipuji, 2) 5 keluhan yang paling sering muncul (dengan jumlah kemunculan dan 1 kutipan asli tiap keluhan),
3) kata-kata yang dipakai pembeli untuk menjelaskan masalahnya. Jangan menambah info yang tidak ada di teks.
[tempel ulasan]
```
**B. Cari keluhan yang berulang → cek lantai nampan**
```
Dari ulasan di atas, kelompokkan keluhan jadi tema. Untuk tiap tema: seberapa sering muncul, seberapa parah (kecil/sedang/berat),
dan apakah orang sudah mau bayar untuk solusinya (ada bukti di teks atau tidak). Tandai tema yang buktinya lemah.
```
**C. Bikin versi penawaran untuk diuji (ubah satu variabel)**
```
Produkku: [deskripsi], harga sekarang [harga], pembeli: [siapa]. Keluhan utama mereka: [dari langkah B].
Buat 3 versi penawaran yang masing-masing hanya mengubah SATU hal (versi A: isi paket, versi B: harga/skema bayar, versi C: cara
jualan/saluran). Untuk tiap versi tulis: judul penawaran, 2 kalimat penjelasan, dan cara mengukur berhasil/tidaknya dalam 7 hari.
Jangan pakai klaim hasil yang tidak bisa dibuktikan.
```
**D. Uji ukuran pasar (nampan)**
```
Bantu aku memperkirakan ukuran pasar untuk [produk] di [wilayah]. Tunjukkan langkah hitungnya dan asumsi tiap langkah, tandai
asumsi yang harus aku cek sendiri, dan sebutkan sumber data publik yang bisa aku pakai untuk mengeceknya. Jangan mengarang angka.
```

Catatan: angka peluang di video (16,7 % / 83,8 % / 99,99999 %) hanya berlaku untuk dadu sungguhan; di bisnis, "peluang" naik
karena tiap lemparan ngasih pelajaran — bukan jaminan. Tidak ada janji hasil di lembar kerja ini.
