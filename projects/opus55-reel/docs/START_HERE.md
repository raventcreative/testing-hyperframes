# CLAUDE OPUS 5.5 — AIpreneur Mascot Reel

**Paket eksekusi untuk Claude Code** · Video portrait 1080 × 1920 · target ±30 detik · 30 fps

## Cara pakai (3 langkah)

1. **Ekstrak ZIP ini ke folder proyek Claude Code yang sudah memiliki maskot 3D dan voice-over (VO).** Jangan buat proyek mascot baru. Folder hasil ekstrak bernama `Claude_Opus55_Reel_Kit`.
2. Buka Claude Code di **folder proyek yang sama**, lalu kirim: **“Baca `Claude_Opus55_Reel_Kit/CLAUDE_CODE_MASTER_PROMPT.md` secara utuh dan jalankan instruksinya. Sebelum mengedit, cari dan identifikasi aset maskot serta VO yang sudah ada. Buat preview untuk approval sebelum final render.”**
3. Jika Claude Code meminta izin untuk instalasi dependency atau rendering, evaluasi dahulu. Setelah preview disetujui, minta render final MP4 dan file proyek yang editable.

## Penting: aset yang memang tidak ada di ZIP

- **Maskot 3D dan VO** sudah ada di proyek Claude Code milik user; cari file aslinya dan pakai tanpa mengganti identitas maskot atau mengarang VO.
- **Rekaman layar asli** sengaja **tidak disertakan** karena ada nama Recent/Projects, kartu proyek dan data pribadi. Tim sudah membedah urutannya dan menuliskan timing dalam file analisis. Bangun tampilan Google → Claude → Claude Code yang bersih dari rekaman tersebut sebagai *motion reenactment*. **Jangan meminta atau memasukkan rekaman asli ke final tanpa redaksi total dan pengecekan frame-by-frame.**
- **Video referensi lama** hanya acuan level motion, bukan sumber adegan atau aset. Konsep Pocket Universe benar-benar baru.
