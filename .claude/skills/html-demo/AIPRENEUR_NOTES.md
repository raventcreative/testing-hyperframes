# How this skill applies to the AIpreneur projects (added 2026-11-20)
Source: github.com/MengTo/Skills (agent-skills/web-design/html-demo), MIT licence (see LICENSE), copied unmodified.

- Deliverable here is a LIVE HTML window on a web page (landing page, download page, product tour) — not an MP4.
  For Reels/MP4 keep using HyperFrames (/voxel-reels, /aip-remake, /automation-demo, /masterpajak-video).
- Its core rule matches our engines: every frame is a pure function of time (`View(t)`), fixed stage + one CSS scale,
  scripted pointer, real labels. Reuse its timing numbers in our software-demo reels (/automation-demo):
  pointer arrives 0.3–0.6 s early, click 0.15–0.2 s, glide 0.5–0.9 s cubic-bezier(0.55,0,0.25,1), typing ~50 chars/s,
  hold ≥1 s on each result, results appear via a working state → reveal → settle (never pop in).
- Good uses for the client: animated app/agent demos on AIpreneur / AIpreneur Automation / SKINKU landing pages,
  interactive "how the AI system works" tours, hero windows replacing GIF/MP4 screen recordings.
- Brand: apply AIpreneur colours/fonts from skills/aipreneur-reels-studio/references/brand.md inside the window chrome
  when the page is ours; use one owned example subject (never a client's real data).
