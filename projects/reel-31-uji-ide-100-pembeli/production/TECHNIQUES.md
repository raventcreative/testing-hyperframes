# reel-31 — uji ide ke 100 pembeli (white)

Reference: client-supplied reel `b2e359b7` (an idea tested on 100 simulated buyers). Beats followed in its order;
every product/tool name, logo, UI, free-giveaway hook and its "comment X" CTA dropped. Business context:
**produk digital / kelas online** (fresh vertical — not AC service, laundry, generic shop, workshop, vet, salon,
barbershop, restaurant, beauty clinic, property, catering, fashion e-commerce or travel).

## Techniques applied
From `.claude/skills/aipreneur-reels-studio/references/technique_bank.md` + `mascot_robot_recipes.md`:

1. **Hook shows the problem, never states it** — the class goes live, the sign-up board stays at 0 and the ad-spend
   chips drift down. No slogan card, no red badge (`#294b77` is the only accent on white).
2. **Shared element / match cut** — the camera punches through the offer card and the app opens already framed on the
   same idea, so the object carries the hand-off.
3. **Process fill** — the 100-buyer grid builds row by row with a counter, then the same panel splits into the
   MAU / NGGAK columns instead of cutting to a new screen.
4. **One object per scene, never repeated**: offer card + burn chips → flow rail → round advisor table →
   10×10 buyer grid → two-column sort → speech bubbles → objection→lever rows → calculator + printed rows →
   two verdict plates → two comparison bar strips → ghost grid + SIMULASI plate → next-step ticket.
5. **A different transition every beat** — zoom punch-through, camera pull-back reveal, tab cut, stripes, in-scene
   split, 3D swing, shutter, cross-fade + zoom-out reveal, card flip, cross-slide, recede, zoom-through.
6. **Camera never still, never sliced** — one eased move per scene; every close-up is framed so the no-cut guard keeps
   its unit whole (the first shot was re-framed after a 2.0× punch blanked the idea card).

## Client rules honoured (2026-11-23)
- Robot checked at rest, all three side rises, gesture extremes and the CTA: no torn geometry, no snapped limbs.
- Hands alternate — the robot crosses sides (home / center / right / upL / upR), so `point`/`wave` swap arms, and
  `beat` alternates on its own.
- VO tags kept in one narrow band ([curious]/[confident]/[playful]); longest pause 0.48 s, no padding added.
- 57.4 s VO in a 58.2 s composition (target 45–60 s).
