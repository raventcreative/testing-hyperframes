## Code conventions (as in s01/s06 — deviations break the render)
- `<template>` + `<style>` + ONE root `<div data-composition-id="ID" data-width="1080" data-height="1920">` + `<script>` IIFE.
- **The runtime strips the id of the template root** → never select the root by id; look elements up with `document.getElementById`
  on unique PREFIXED ids (`s07-…`), classes prefixed too, SVG ids prefixed.
- Timeline: `gsap.timeline({ paused: true })`, the `_sc` patch, `ft` (fromTo, immediateRender:false), `I(el, vars)` for initial states,
  end `tl.set({}, {}, D - 0.01)`, the seek-order render patch, `window.__timelines["ID"] = tl`. Timeline duration must equal DUR.
- Deterministic and seekable: no Math.random (seeded PRNG), no Date, no CSS animations/transitions, no requestAnimationFrame, **no
  onUpdate callbacks** (they don't fire reliably under the runtime's seeks — for counters/typing use per-character / per-value `tl.set`
  windows like s01's digits and s06's typing).
- Known runtime pitfalls (found by earlier agents): (1) chaining several `fromTo` tweens on the same SVG `attr` (or the same `clip-path`
  string) can start from stale values — give each attribute ONE tween, or animate a wrapper's transform instead; CSS transform/opacity
  chains are fine. (2) `svgOrigin` inside an SVG that is itself CSS-transformed rotates around the wrong point — rotate nested `<g>`
  wrappers or use CSS transforms on HTML. (3) An `attr` tween whose start differs from its `I()` value ignores the `I()` value.
- Performance (render on 4 CPUs): no full-screen blur/feTurbulence per frame; ≤ ~400 animated elements per scene; transforms + opacity.
- Assets only from `assets/` (no network). No emoji glyphs (Poppins has none) — use icons.
