# Link dan panduan singkat HYPIT — untuk balasan komentar

Sumber resmi:

- Repository: https://github.com/hypit-ai/hypit
- Panduan quickstart: https://github.com/hypit-ai/hypit/blob/main/docs/quickstart.md
- Lisensi: https://github.com/hypit-ai/hypit/blob/main/LICENSE

## Cara mulai

1. Siapkan coding agent seperti Claude Code di komputer; cek fitur dan setup aktual di lingkungan milikmu.
2. Jalankan instalasi skill sesuai panduan resmi Hypit (yang ditunjukkan pada repositori):

   ```bash
   npx skills add hypit-ai/hypit -g
   ```

3. Di coding agent, gunakan skill yang baru terpasang dan berikan video referensi **yang boleh kamu gunakan**, tujuan video baru, rasio output, VO/audio milikmu, serta daftar perubahan (hook, presenter, produk, bahasa).
4. Minta agent menyiapkan proyek editable, preview, dan pemeriksaan hasil. Sesuaikan command eksekusi/video output dengan instruksi yang sebenarnya terpasang. Skill install tidak otomatis membuktikan executable/video renderer sudah tersedia.
5. Verifikasi kualitas, akurasi, hak aset, biaya model/API, dan ketentuan lisensi sebelum publikasi atau dijual sebagai layanan.

**Penting:** Hypit bukan jaminan video viral. Video orang lain boleh dipelajari sebagai referensi struktur, tetapi footage, logo, musik, atau aset yang tidak kamu miliki tetap memerlukan hak penggunaan. Software open source tidak berarti semua jenis hosting/resale diperbolehkan. Biaya pihak ketiga bisa berlaku.
