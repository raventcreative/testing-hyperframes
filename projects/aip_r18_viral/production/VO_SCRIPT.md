## ATM: what we changed
**Amati** — ide yang berguna: video bisa dites dulu ke AI yang memprediksi perhatian penonton (skor + titik hook) *sebelum* diposting.
Mekanisme hook: "sekarang kamu bisa memprediksi seberapa viral reel berikutnya" + "gratis" + bukti sosial (statistik views/followers
kreator). Struktur: hook → statistik pribadi → nama alat → cara kerja ("otak manusia", "ribuan jam data otak") → breakdown per detik +
grafik retensi → CTA kata kunci, dikirim lewat DM.
**Tiru** — hanya mekanismenya: satu plugin Claude Code gratis untuk ngetes reel sebelum posting, dijelaskan alat → cara kerja → hasil →
CTA kata kunci.
**Modifikasi** (wajib):
1. **Hook sendiri, sudut beda** — "Sebelum posting, reels kamu bisa gladi resik dulu di depan penonton AI." Sudutnya *gladi resik*
   (latihan sebelum tampil), bukan "prediksi seberapa viral". Tanpa statistik, tanpa janji viral.
2. **Struktur, urutan, metafora visual sendiri** — hook → nama + cara pasang (2 perintah asli di layar) → batas klip 15 detik + cara
   prediksinya → **rapor** (3 hasil) → cara *membaca* hasil (puncak hook telat = pembukaan kelamaan) → cara *memperbaiki* (pindah kalimat
   terkuat ke detik 1, buang yang bertele-tele, tes ulang) → kasus UMKM (tes A/B sebelum bayar iklan) → peringatan jujur → CTA. Metafora per
   beat milik kita: panggung latihan bertirai navy + penonton AI di kursi; colokan plugin + kartu terminal; strip film + kurung 15 detik;
   satu penonton AI + 4 baris sensor; **rapor sekolah**; 15 batang detik + cap KELAMAAN; jalur editor (blok klip dipindah/digunting);
   dua versi reel + dompet iklan terkunci; **prakiraan cuaca** + cap BUKAN JAMINAN; penonton asli + grafik insight. Gaya LIGHT AI PRENEUR,
   maskot + robot kita, produk contoh fiktif "Sambal" (berlabel CONTOH). Tidak ada kartu HP neon, otak 3D, peta dunia, grafik
   hijau→merah, kotak skor neon, atau warna gelap referensi; tidak ada logo Higgsfield/Claude (nama sebagai teks).
3. **Sudut praktisi** — tidak ada klaim hasil atau pemakaian pribadi Freddie (tidak kami ketahui → tidak dikarang). Semua skor di layar
   berlabel CONTOH / ILUSTRASI. Statistik kreator referensi (700 rb views / 5 rb followers / 10 posting) **tidak dipakai sama sekali**.
4. **Nilai untuk penonton Indonesia** — contoh UMKM (sambal), *tes dulu sebelum keluar duit buat boost iklan*, tips praktis yang
   referensi tidak punya: klip maksimal 15 detik → tes **15 detik pertama** (bagian hook); cara membaca puncak hook + cara memperbaiki;
   bandingkan prediksi dengan **insight asli** setelah posting; di DM: perlu akun Higgsfield, video diunggah ke server Higgsfield (jangan
   unggah video klien tanpa izin), cek biaya terbaru.
5. **CTA dan penutup sendiri** — kata kunci **VIRAL** ditentukan klien (kebetulan sama dengan kata kunci referensi); kalimat penutup
   kita "Komen VIRAL, aku kirim lewat DM." dan isi DM milik kita (`production/DM_VIRAL.md`: cara pasang + checklist hook 15 detik).
   Tanpa "follow kita untuk update".

## Fakta yang dicek (2026-11-12)
- **Apa alatnya** — *Virality Predictor* adalah fitur **Higgsfield AI**: analisis video (video masuk → laporan teks), nama teknisnya
  `brain_activity`, hasil: skor keseluruhan, **detik puncak hook**, skor *sustain*/hold, wilayah respons terkuat/terlemah, plus link
  "Open report" ke dashboard visual `…/apps/virality-predictor?resultJobId=…`; skill menyebutnya "an objective attention proxy for creative
  testing" (nilai Default Mode tinggi = indikasi pikiran melayang). Sumber resmi: https://github.com/higgsfield-ai/skills (README, INSTALL.md,
  `higgsfield-generate/SKILL.md`, `higgsfield-generate/references/media-inputs.md`, v0.14.0) — dibaca langsung (raw.githubusercontent.com).
  Deskripsi tool di server MCP resmi Higgsfield: "predicts a video's virality potential, engagement, attention, audience response, retention
  risk, hook strength … with an interactive dashboard".
- **Plugin Claude Code-nya** — plugin `higgsfield` dari marketplace `higgsfield-ai/skills` (`.claude-plugin/marketplace.json` +
  `plugin.json`, author "Higgsfield AI", **lisensi MIT**, © 2026 Higgsfield AI; 9 skill, Virality Predictor ada di skill
  `higgsfield-generate`). Cara pasang (README, opsi "Claude Code marketplace"): di Claude Code ketik
  `/plugin marketplace add higgsfield-ai/skills` lalu `/plugin install higgsfield@higgsfield`. Skill memakai Higgsfield CLI
  (github.com/higgsfield-ai/cli, MIT; dipasang otomatis oleh skill bila belum ada) dan butuh login akun: `higgsfield auth login`. Pemakaian:
  minta Claude "analisa video ini" (skill mengarahkan ke Virality Predictor) atau `higgsfield generate create brain_activity --video ./reel.mp4 --wait`.
  Alternatif resmi lain: `npx skills add higgsfield-ai/skills`, `gh skill install higgsfield-ai/skills`, atau clone + `./setup`.
- **"Gratis"** — plugin/skill-nya gratis (MIT). Analisisnya jalan di server Higgsfield dengan akunmu. Saat rilis (Mei 2026) akun X resmi
  Higgsfield menulis "Virality Predictor is in experimental preview version - does not consume credits" (terbaca lewat judul hasil
  pencarian; x.com tidak dibuka). Harga hari ini tidak bisa dicek dari sini → VO hanya bilang *plugin-nya gratis*; layar: "Gratis · lisensi
  MIT" + "Perlu akun Higgsfield"; DM: cek biaya di akunmu.
- **Input & hasil (halaman resmi)** — https://higgsfield.ai/apps/virality-predictor (teks halaman lewat indeks WebSearch; domainnya diblokir
  dari sandbox ini): unggah klip **maksimal 15 detik**, format apa saja, vertikal/horizontal; "a modeled audience watches while the tool
  maps the brain response across vision, sound, memory, attention, and language"; hasil: virality score, peak hook timestamp, hold rate,
  heatmap wilayah otak. → VO: "maksimal lima belas detik", "visual, suara, bahasa, fokus", "skor viral, detik puncak hook, dan hold rate".
- **Klaim "data otak" (dicek ke model/paper)** — Higgsfield **tidak** mempublikasikan model atau data latihnya (tidak ada paper); kata-kata
  resminya hanya "modeled audience" / "maps the brain response". Liputan pihak ketiga menduga dasarnya **TRIBE v2** dari Meta FAIR —
  https://github.com/facebookresearch/tribev2 (README dibaca langsung): "a deep multimodal brain encoding model that predicts fMRI brain
  responses to naturalistic stimuli (video, audio, text)", prediksi untuk subjek "rata-rata" di mesh korteks fsaverage5, **lisensi CC BY-NC
  4.0** (non-komersial), paper arXiv:2605.04326 (d'Ascoli dkk., 2026). Ringkasan paper (lewat indeks pencarian; arxiv.org diblokir di
  sandbox) menyebut ±1.000+ jam fMRI dari ±720 subjek; posting Meta yang dikutip pihak lain menyebut 500+ jam dari 700+ orang — angkanya
  tidak konsisten dan hubungan TRIBE ↔ Higgsfield **tidak dikonfirmasi**. Model semacam ini memprediksi aktivasi otak, bukan views atau
  retensi. **Keputusan:** klaim "ribuan jam data otak manusia dari seluruh dunia" dibuang; kita hanya bilang AI-nya *memprediksi respons
  otak penonton* (sesuai kata Higgsfield) dan menulis di layar "Prediksi model AI · bukan scan otak penontonmu".
- **Tidak dipakai:** statistik pribadi kreator referensi; "second-by-second breakdown" sebagai fitur pasti (hanya ilustrasi berlabel);
  nama model/dataset di VO; angka bintang GitHub.
- Catatan: sumber pihak ketiga (pasqualepillitteri.it, Product Hunt, Skool) hanya terbaca sebagai potongan pencarian dan **tidak** dipakai
  sebagai dasar klaim; semua yang diucapkan berasal dari repo resmi Higgsfield dan halaman resmi Higgsfield.
