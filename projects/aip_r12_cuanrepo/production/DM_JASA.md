# DM untuk yang komen JASA — 5 alat gratis di GitHub + catatan lisensinya
(dicek 12 Nov 2026 di halaman GitHub resmi; lisensi bisa berubah, selalu baca file LICENSE terbaru sebelum dipakai buat klien)

Halo! Ini daftar yang aku janjiin. Alatnya gratis, yang kamu jual itu kerjaan dan hasilnya.

1. **Postiz** — jadwalin postingan ke banyak akun sosmed dari satu tempat (Instagram, TikTok, Facebook, LinkedIn, YouTube, dan lainnya).
   Ide jasa: kelola sosmed toko & UMKM.
   https://github.com/gitroomhq/postiz-app
   Lisensi: AGPL-3.0 — boleh dipakai komersial; kalau kamu MENGUBAH kodenya lalu menjalankannya untuk orang lain, kode hasil ubahanmu wajib
   dibuka juga. Fitur AI di versi self-host pakai API key kamu sendiri (bayar ke penyedianya).

2. **AutoClip** — video panjang (podcast, live, kelas) dipotong jadi klip-klip pendek lengkap subtitle, judul, dan caption.
   Ide jasa: potong klip buat podcaster & seller yang rutin live jualan.
   https://github.com/zhouxiaoka/autoclip  (panduan Inggris: README-EN.md)
   Lisensi: MIT. Aplikasinya gratis; kalau pakai model AI cloud, biayanya dihitung penyedia model. Bisa juga pakai model lokal (Ollama).

3. **Chatwoot** — chat dari WhatsApp, Instagram, website, email, dll. masuk ke satu inbox, bisa dibalas bareng tim.
   Ide jasa: setup + jadi admin chat buat toko online.
   https://github.com/chatwoot/chatwoot
   Lisensi: MIT, KECUALI folder `enterprise/` yang punya lisensi sendiri. WhatsApp disambungkan lewat WhatsApp Cloud API resmi Meta
   (perlu verifikasi bisnis) atau Twilio — cek panduan resminya di chatwoot.com/hc/user-guide sebelum janji ke klien.

4. **OpenHands** — agen AI yang ngoding sesuai perintahmu (pakai model AI pilihanmu).
   Ide jasa: website / landing page UMKM. Hasilnya TETAP kamu cek sebelum diserahkan.
   https://github.com/OpenHands/OpenHands
   Lisensi: MIT. Catatan keamanan dari README: agennya bisa akses file di komputermu — jalankan di folder/proyek khusus.

5. **Remotion** — bikin video lewat kode (React): satu template, banyak versi video (misalnya video tiap produk).
   Ide jasa: video produk untuk toko yang produknya banyak.
   https://github.com/remotion-dev/remotion
   Lisensi KHUSUS: gratis untuk perorangan, usaha sampai 3 karyawan, organisasi nirlaba, dan masa evaluasi. Usaha yang lebih dari 3
   karyawan wajib beli Company License. Kalau kamu kerja bareng tim klien, jumlah orangnya bisa dihitung gabungan — baca aturan & FAQ
   lisensinya di remotion.dev sebelum menerima proyek.

Cara mulainya: pilih SATU jasa dulu → latihan di usaha teman/keluarga → jadikan contoh hasil (portofolio) → baru tawarkan ke klien,
dengan harga sesuai besar kerjaannya. Tidak ada jaminan penghasilan; yang dibayar klien adalah hasil kerja yang beres.
